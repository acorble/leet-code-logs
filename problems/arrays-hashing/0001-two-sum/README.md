# 1. Two Sum

- URL: https://leetcode.com/problems/two-sum/
- 難易度: easy
- カテゴリ: arrays-hashing
- 解いた日: 2026-08-30

## 問題の要約

配列 nums の中から、足して target になる 2 つの要素のインデックスを返す。

## 考えたこと / アプローチ

二重ループは O(n^2)。「target - num を過去に見たか」を辞書で持てば 1 パスで済む。
値 -> インデックスの dict を作りながら走査する。

## 計算量

- 時間: O(n)
- 空間: O(n)

## 学び・再利用できるパターン

「2 つの要素の組み合わせ」を探すときは、片方を固定してもう片方をハッシュで引く。
3Sum など上位問題の土台になる。
