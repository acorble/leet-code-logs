# talk-scripts（話す台本）

coding interview で英語で話すときに使い回せる言い回しと、説明の型を一か所にまとめる。
問題ごとの記録（`problems/*/english/`）のレビューで見つかった表現をここに集めていく。

- [phrases.md](phrases.md) — 面接の流れに沿った定型句集と、自分の癖（間違えやすい語）

## 使い方

- mock や一人練習の前に、[phrases.md](phrases.md) を流し読みする。全部を覚えるより、
  各節の 1〜2 個を口に出せるようにするほうが効く
- 原稿として読み上げるためのものではない。言い回しの「型」を体に入れるためのもの
- 各表現の「出典」は、その表現が必要になった記録へのリンク。どの場面で詰まったかを思い出せるようにしている

## 足し方

`/mock-log` のレビューで、どの問題でも使える表現が見つかったら Claude が足す。
同じ意味の表現がすでにあれば増やさず、出典だけ足す。自分で見つけた表現を足してもよい。
