## 問題の要約

ヒストグラムの棒の高さ `heights` が与えられる（棒の幅はすべて 1）。
隣り合う棒にまたがって描ける長方形のうち、いちばん大きい面積を返す。長方形の高さは、使う棒の中でいちばん低い棒で決まる。

### 単調 Stack で「その棒を高さにした長方形」をいつ確定させるか

Stack には `(高さ, 左端)` を、下から上へ高さが**上がっていく**順に積む。

- 新しい棒が Stack の上より**低い**と、上の棒はもう右へは広げられない（低い棒が壁になる）。
  左端は積んだときに記録してあるので、その場で面積 `高さ × (i - 左端)` が確定する → pop
- pop した棒は自分より高かったので、新しい低い棒はそこまで左に広げられる。
  だから**pop した棒の左端を、新しく積む棒の左端として引き継ぐ**（`newPositionLeft = positionLeft`）
- 最後まで残った棒は、右端まで広げられたということなので、幅は `len(heights) - 左端`

```
heights: 2 1 5 6 2 3
i=1 (1): 2 を pop → 面積 2×1=2。1 は左端 0 を引き継いで (1, 0) で積む
i=4 (2): 6 を pop → 6×1=6、5 を pop → 5×2=10。2 は左端 2 を引き継いで (2, 2)
最後:    (3,5) → 3×1、(2,2) → 2×4=8、(1,0) → 1×6=6   → 最大 10
```

### 739 との比較

| | [739. Daily Temperatures](../0739-daily-temperatures) | 84 |
| --- | --- | --- |
| Stack の並び | 下から上へ下がっていく | 下から上へ上がっていく |
| pop するとき | 新しい日のほうが暖かい | 新しい棒のほうが低い |
| pop したときに決まるもの | その日の答え（何日待つか） | その棒を高さにした長方形の面積 |
| 最後まで残ったもの | 答えは 0（暖かい日が来なかった） | 右端まで広げられる |

どちらも「自分より大きい（小さい）ものが来た瞬間に答えが決まる」形で、比べる向きが逆なだけ。
[853. Car Fleet](../0853-car-fleet) の Stack 版も同じ仲間。

### 細かい点

- `h < stack[-1][0]` の `<` を `<=` にしても答えは変わらない。同じ高さの棒は、どちらかがもう一方の左端を引き継いで同じ長方形を数えるため
- 最後の `while stack` は、`heights` の末尾に高さ 0 の棒を足すと 1 つのループにまとめられる（0 はどの棒より低いので全部 pop される）
