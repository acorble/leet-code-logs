## 問題の要約

木の中で最も長い経路の**辺の数**を返す。経路は根を通らなくてよい。
あるノードを頂点とする経路の長さは「左の深さ + 右の深さ」で決まる。

## 計算量

- 時間: O(n × h) — 全ノードを BFS で回り、**各ノードで深さを測り直している**。
  偏った木では最悪 O(n^2)
- 空間: O(n) — queue と再帰スタック

深さを下から持ち上げれば、測り直しが消えて O(n) になる
（→ [110. Balanced Binary Tree](../0110-balanced-binary-tree) で実際にその形を書いている）。

## 学び・再利用できるパターン

- **直径 = 各ノードでの「左の深さ + 右の深さ」の最大値**。この言い換えに気づけば、
  あとは全ノードを回るだけ。最長経路が根を通るとは限らない点が肝
- 長さは「ノード数」ではなく**辺の数**。葉 1 つだけの木は 0
- **同じ計算を繰り返していないか**を疑う。ここでは各ノードで `maxOfDepth` を
  呼び直しているため、同じ部分木の深さを何度も measure している。
  深さを返しながら答えを更新する後順走査にすれば 1 回の走査で済む
