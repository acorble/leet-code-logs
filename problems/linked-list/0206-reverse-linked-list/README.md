## 学び・再利用できるパターン

- **連結リスト反転の基本形**。`prev` / `curr` の 2 本を持ち、
  次のノードを `tmp` に退避してから `next` を張り替える。4 行で終わる

  ```python
  tmp = curr.next     # 先に退避（張り替えると辿れなくなる）
  curr.next = prev    # 向きを反転
  prev = curr         # 2 本を 1 つ前進
  curr = tmp
  ```

- **退避してから張り替える**のが連結リストの鉄則。
  同じ型を [143. Reorder List](../0143-reorder-list) の 3 箇所すべてで使っている
- 反転後の先頭は `curr` ではなく **`prev`**。ループを抜けたとき `curr` は None で、
  `prev` が最後に処理したノード（= 元の末尾 = 新しい先頭）を指している
- 1 回目は `if not head: return None` が要ったが、2 回目は不要。
  `prev = None` で始めるので、空リストならそのまま None が返る。
  **初期値を正しく置くと、特殊ケースの分岐が消える**

### 2 回目で変わったこと

1 回目は **値をコピーして新しいノードを作り直していた**（`ListNode(curr.next.val)`）。
2 回目は既存のノードの `next` を張り替えるだけにしたので、追加メモリが要らなくなった。

| | 1 回目 | 2 回目 |
| --- | --- | --- |
| ノード | 新しく n 個作る | 作らない |
| 空間 | O(n) | **O(1)** |
| 元のリスト | そのまま残る | 破壊される（反転される） |
| 行数 | 12 行 | 6 行 |

「新しく作る」か「繋ぎ替える」かは連結リストで毎回出てくる分かれ道。
問題が「in-place で」と言っていなくても、**繋ぎ替えられるなら繋ぎ替える**ほうがよい。

### 3・4 回目: 再帰で書く

末尾まで潜ってから、**戻りがけに向きを反転する**。

```python
reversedHead = self.reverseList(head.next)   # 先に後ろを全部反転させる
head.next.next = head                        # 自分の次に、自分を指させる
head.next = None                             # 自分の next を切る
return reversedHead                          # 新しい先頭は変わらず持ち上げる
```

- `head.next.next = head` が肝。**自分の次のノードから、自分へ矢印を向け直す**
- `head.next = None` を忘れると、2 ノード間で矢印が相互に向いて循環する
- `reversedHead`（新しい先頭 = 元の末尾）は、途中で変わらず上まで持ち上げるだけ
- 反復版が「前から順に向きを変える」のに対し、再帰版は「**後ろから順に**」。
  同じ結果に逆方向から到達している

**4 回目は 3 回目の整理**で、終了条件を 1 つにまとめただけ。

| | 3 回目 | 4 回目 |
| --- | --- | --- |
| 終了条件 | `if not head: return None` と `else: return head` の 2 箇所 | `if not head or not head.next: return head` の 1 箇所 |
| 行数 | 9 行 | 6 行 |

`head` が None のときは `head` を返せばよい（None が返る）ので、
2 つの終了条件を 1 つにまとめられる。**2 回目で `prev = None` にして分岐を消したのと同じ発想**。

### この 4 行がのちの土台になった（時系列）

- **7/3**: 1 回目（新ノード）→ 2 回目で反復 in-place の基本形を獲得
- **7/4**: 3 回目（再帰）→ 4 回目で終了条件を整理。同じ問題を 2 通りの手段で書いた
- **7/11**: [143. Reorder List](../0143-reorder-list) の 2 回目で
  「後半を反転する」部分に **2 回目の反復版**をそのまま使い、O(1) 空間を達成

143 で反復版を選んだのは正しい。再帰版だと空間 O(n) になり、
143 の狙い（O(1) 空間）が崩れる。
