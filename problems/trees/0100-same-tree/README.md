## 問題の要約

2 つの二分木が完全に同じか（形も値も一致するか）を判定する。

## 考えたこと / アプローチ

<!-- ここは本人が手で書く欄。Claude は見出しだけ用意し、中身は書かない。 -->

### 1 回目

<!-- 最初に思いついた方針、詰まった点、気づき -->
Recursionを使ってDFSで解いた。Recursion自体はもう板についてきた、というかRecursionでしかほぼ解いてない。BFSやIterative DFSでも解けるようには一応しておく。

## 計算量

- 時間: O(n) — 一致しない箇所が見つかった時点で打ち切られる
- 空間: O(h) — 再帰スタック。木が偏ると最悪 O(n)

## 学び・再利用できるパターン

- **2 本の木を同時に降りる再帰**。片方だけを走査するのではなく、p と q を対にして
  同じ位置に降りていく。「2 つの木を比べる」系はすべてこの形
- 終了条件を **3 分岐で書き切る**のが要点:
  1. 両方 None → True（末端まで一致した）
  2. 片方だけ None → False（形が違う）
  3. 両方ある → 値を比べ、左右をそれぞれ再帰
  この 3 つを先に潰しておくと、最後の再帰が 1 行で書ける
- ここで書いた判定は [572. Subtree of Another Tree](../0572-subtree-of-another-tree)
  の内側でそのまま使える。572 は「候補の根を探す」処理を外側に足しただけ。
  → 小さい問題が、そのまま次の問題の部品になる
