## 問題の要約

各行が昇順で、かつ前の行の末尾より次の行の先頭が大きい行列から target を探す。
= **全体を 1 列に並べると、そのまま昇順**になっている。

## 計算量

- 時間: O(log(m × n)) — 全体を 1 本の配列とみなして半分に切り続ける
- 空間: O(1)

## 学び・再利用できるパターン

- **2 次元を 1 次元とみなす**のが核心。行列の性質から、平坦化すると全体が昇順になる。
  あとは普通の二分探索

  ```python
  row = middle // len(matrix[0])   # 何行目か
  col = middle %  len(matrix[0])   # その行の何番目か
  ```

  `//` と `%` のペアで添字を 1 次元 ⇔ 2 次元に変換する。
  グリッドを扱う問題で繰り返し出てくる
- 行を先に二分探索してから行内を二分探索する解法もあるが、
  平坦化すれば **二分探索は 1 回で済む**
- **標準形の二分探索で書けている**。`while left <= right` で範囲が空になるまで回し、
  `middle ± 1` で範囲を必ず縮め、抜けたら `return False`。
  ループ後の後始末が要らない形

### 制約に守られている点

`len(matrix[0])` を無条件に使っているので、行が 0 個・列が 0 個だと落ちる。
この問題の制約は 1 ≤ m, n なので問題にならない。
