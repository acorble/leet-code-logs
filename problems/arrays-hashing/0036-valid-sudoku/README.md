## 問題の要約

9x9 の数独の盤面が、**今埋まっているマスについて**ルールを守っているかを判定する。
各行・各列・各 3x3 ブロックの中で、1〜9 の数字が重複していなければよい（空きマスは `.`。解けるかどうかは問わない）。

## 計算量

盤面の大きさは 9x9 に固定なので、どの解き方でも厳密には O(1)。
盤面を n x n（今回は n = 9）と考えると:

- 時間: **O(n²)** — 行・列・ブロックのそれぞれで全マスを 1 回ずつ見るので、合計で全マスを 3 回見る
- 空間: **O(n)** — 取り出した 9 マスの配列と、重複チェック用の HashMap

## 学び・再利用できるパターン

### 同じチェックを 1 つの関数にまとめる

行・列・ブロックは、どれも「9 マスの中に同じ数字が 2 回出てこないか」という**同じ判定**。
この解答は、3 種類をそれぞれ 9 マスの `char[]` に取り出してから、同じ `isValidArray` に渡している。
判定を 1 か所に書くので、間違いにくく読みやすい。

`isValidArray` の中身は [217. Contains Duplicate](../0217-contains-duplicate) と同じ「既に出たかどうか」の判定。

### 1 周で全部チェックする: ブロックの番号は `(r // 3, c // 3)`

盤面を 3 回見る代わりに、各マスを 1 回見るだけで、そのマスが属する行・列・ブロックの 3 つを同時にチェックできる。

```python
rows = [set() for _ in range(9)]
cols = [set() for _ in range(9)]
boxes = [set() for _ in range(9)]
for r in range(9):
    for c in range(9):
        v = board[r][c]
        if v == ".":
            continue
        b = (r // 3) * 3 + c // 3        # 0〜8 のブロック番号
        if v in rows[r] or v in cols[c] or v in boxes[b]:
            return False
        rows[r].add(v); cols[c].add(v); boxes[b].add(v)
return True
```

`r // 3` と `c // 3` は 0〜2 になり、「上から何番目・左から何番目のブロックか」を表す。
9 個の `isValidBox(…)` を手で並べる必要がなくなる。

### 細かい点（Java）

- 「既に出たか」だけを見ているので、`Map<Character, Integer>` の値（1）は使っていない。`Set<Character>` で足りる
- `isValidBox` で `List<Character>` に集めてから `char[]` に詰め直しているが、最初から `new char[9]` に入れていけば 1 段で済む
- `isValidBox(0, 0, …) || … ` の 9 個は、`for (int r = 0; r < 9; r += 3) for (int c = 0; c < 9; c += 3)` の二重ループにできる
- `if (…) { … };` の `}` の後ろの `;` は不要（空の文があるだけで、動きは変わらない）
