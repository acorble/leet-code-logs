## 問題の要約

1 本道の上で、各車の位置と速さが与えられる。後ろの車は前の車を追い越せず、追いついたら前の車の速さに合わせて一緒に走る（車団 = fleet）。ゴール `target` に到着する車団の数を返す。

## 計算量

- 時間: O(n)（ソートを入れると O(n log n)）
- 空間: O(n)（到着時間のリスト）

## 学び・再利用できるパターン

<!-- 次に似た問題が出たときに思い出したいこと -->

- 「前が詰まると後ろが合わせる」系は、**先頭（ゴールに近い側）から順に見る**。そのために位置でソートする。
  入力の並び順がそのまま意味を持つとは限らない
- 先頭から見て「これまでの最大の到着時間」より遅ければ新しい集団、そうでなければ吸収される。
  集団の到着時間は先頭の車の時間で決まる（単調スタックで、積まれる値が単調増加になる形）
- 比較に使う値を丸めない。切り上げると本来区別すべき 1.2 と 1.5 が同じになる。
  浮動小数点が気になるなら `(target - p) * s2` と `(target - p2) * s` のような掛け算で比べる
