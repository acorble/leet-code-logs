## 問題の要約

根から最も遠い葉までの**ノード数**を返す。空の木は 0。

## 計算量

- 時間: O(n) — 各ノードを 1 回ずつ訪れる
- 空間: O(h) — 再帰スタック。木が偏ると最悪 O(n)

## 学び・再利用できるパターン

- **木の再帰の最小形**。「子の答えを求めて、自分の分を足して返す」。
  終了条件（None なら 0）を先に置き、あとは `max(左, 右) + 1` の 1 行
- この 5 行が、この先の木の問題の土台になる。実際に後続で何度も再利用している（下記）
