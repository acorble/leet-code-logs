## 問題の要約

二分探索木の中で、2 つのノード p と q の**最も深い共通の祖先**を返す。
自分自身も祖先に含む（p が q の先祖なら答えは p）。

## 計算量

- 時間: O(n) — 必ず全ノードを訪れる。p と q が見つかっても走査を打ち切らない
- 空間: O(h) — 再帰スタック。木が偏ると最悪 O(n)

## 学び・再利用できるパターン

- **下から情報を集めて返す DFS**: 各ノードが「左右で p / q が見つかったか」を
  タプルで返し、親がそれを合成する。木の問題で「部分木の状態」が要るときの定石。
  自力でこの形を組めたのは大きい
- ただし **この問題は BST であることを一切使っていない**。`root.val`, `p.val`, `q.val`
  の大小関係を見れば、探索する枝を片方に絞れるはず。Beats 26% はそのぶんの差。
  → 2 回目は「BST の順序をどう使うか」から考える
- 木の LCA は 2 種類ある。今回書いたのは**汎用の二分木**向けの解法で、
  それ単体が 236. Lowest Common Ancestor of a Binary Tree という別問題になっている。
  235 は BST 版なので、もっと単純に解ける
