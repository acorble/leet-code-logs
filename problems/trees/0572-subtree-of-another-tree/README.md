## 問題の要約

木 root のどこかのノードを根とする部分木が、subRoot と完全に一致するかを判定する。
「値も形もすべて同じ」であることが条件。木全体も自分自身の部分木とみなす。

## 計算量

- 時間: O(n × m) — root の各ノードで、最悪 subRoot 全体と突き合わせる
  （n = root のノード数、m = subRoot のノード数）
- 空間: O(h) — 再帰スタック

## 学び・再利用できるパターン

- **「探す」と「比べる」を別の関数に分ける**。外側 (`isSubtree`) が候補となる根を
  すべて回り、内側 (`isSameTree`) が 1 対 1 で一致を判定する。
  この二段構えは「部分構造を探す」系の問題の定番の形
- 内側の `isSameTree` は 100. Same Tree そのもの。
  木の問題は、小さい問題を部品として組み合わせる形になることが多い
- `if root.val == subRoot.val:` で先に根の値を見てから `isSameTree` を呼ぶ枝刈りが効いている。
  無くても正しく動くが、値が違う時点で比較を打ち切れる
- **`not root` と `not subRoot` の場合分け**が要になる。
  「両方 None なら True」「片方だけ None なら False」「両方あるなら値と左右を再帰」
  の 3 分岐に整理すると漏れない
